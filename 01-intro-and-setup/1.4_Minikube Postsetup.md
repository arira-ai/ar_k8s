

# VS Code Terminal Autocomplete for Kubernetes and Minikube

This setup enables intelligent `TAB` autocomplete inside the VS Code integrated terminal for Kubernetes, Minikube, Docker, Helm, and Terraform commands. It improves command execution speed, reduces typing mistakes, and increases operational efficiency during DevOps and Kubernetes administration tasks.

After setup, commands like:

```yaml
kubectl get de<TAB>
kubectl delete po<TAB>
k get svc<TAB>
```

automatically complete into full Kubernetes commands and resources.

<br>


# Step 1: First identify shell

```bash 
echo $SHELL
```

Common outputs:

* `/bin/bash`
* `/bin/zsh`




<br>

# Step 2. Bash Autocomplete Setup

### Ubuntu/Debian

```yaml
sudo apt update
sudo apt install bash-completion -y
```

### RHEL/CentOS

```bash 
sudo yum install bash-completion -y
```

---

## Enable Bash Completion

Add to:

```bash 
~/.bashrc
```

Append:

```bash 
if [ -f /etc/bash_completion ]; then
  . /etc/bash_completion
fi
```

Reload:

```bash 
source ~/.bashrc
```

<br>

#  Step 3. ZSH Autocomplete

## Install zsh

```bash 
sudo apt install zsh -y
```

---

## Enable Completion

Add to:

```bash 
~/.zshrc
```

Append:

```bash 
autoload -Uz compinit
compinit
```

Reload:

```bash 
source ~/.zshrc
```

<br>


# Step 4. Kubernetes Resource Short Names

Useful autocomplete-supported shortcuts:

| Short  | Full Resource          |
| ------ | ---------------------- |
| po     | pods                   |
| deploy | deployments            |
| svc    | services               |
| ing    | ingress                |
| ns     | namespaces             |
| cm     | configmaps             |
| sts    | statefulsets           |
| ds     | daemonsets             |
| rs     | replicasets            |
| pvc    | persistentvolumeclaims |

Examples:

```bash id="a5u9m3"
kubectl get po
kubectl get deploy
kubectl delete svc nginx
```

# Step 5.  Production-Grade DevOps Setup

Add aliases in:

```bash id="y1m6u8"
~/.bashrc
```

or

```bash id="g4u2m7"
~/.zshrc
```

Example:

```bash id="r8u5m1"
alias k=kubectl
alias kgp='kubectl get pods'
alias kgs='kubectl get svc'
alias kgd='kubectl get deploy'
alias kaf='kubectl apply -f'
alias kdel='kubectl delete -f'
```

Reload:

```bash id="m3u7x9"
source ~/.bashrc
```
